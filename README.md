# EPAM AI Engineering Learning Journey

Welcome to my **EPAM AI Engineering Learning Repository**!

This repository documents my structured learning journey into AI Engineering, focusing on understanding, building, evaluating, and optimizing modern AI-powered applications and autonomous agents.

## Learning Roadmap

The repository covers the following areas:

- **Python:** Data structures, APIs, and testing.
- **AI Foundations:** Model capabilities and limitations.
- **Prompt Evaluation:** Systematic testing of prompt quality.
- **AI Agents:** Goals, tools, and memory.
- **Instruction Evaluation:** Measuring and evaluating agent behavior.
- **Context Engineering:** Managing and delivering the right context.
- **AI Fluency:** Using AI as a productivity tool and teammate.
- **AI Orchestration:** Building reliable workflows and tool chains.
- **A2A Communication:** Agent delegation and communication.
- **MCP Protocol:** Connecting AI models with external tools and data.
- **Agent Harness:** Runtime, observability, and retry mechanisms.
- **Security:** Prompt injection prevention and secure access.
- **Guardrails:** Implementing safety limits and validation.
- **Token Optimization:** Reducing token usage, cost, and latency.
- **Agentic Tools:** Exploring frameworks and tools for building AI agents.
- **AI Agent Review:** Evaluating agent behavior, performance, and safety.

## Objective

To develop practical AI Engineering skills by combining theoretical understanding with hands-on coding, experimentation, and real-world implementations.

**Learning by building, experimenting, and continuously improving.**
